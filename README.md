# Göteborg Energi El-tariff (HACS)

En Home Assistant-integration som hämtar nätavgifter och lastnivåer från Göteborg Energis Grid Tariff API.

## Installation via HACS
1. HACS → Integrations
2. Custom repositories → lägg till:
   https://github.com/MaxwellErnst/ge_eltariff
3. Category: Integration
4. Installera och starta om Home Assistant

## Sensorer
- GE Current Price
- GE Next Price
- GE Current Level
- GE Current Level Text
